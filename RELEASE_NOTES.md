# Plugsalot alpha

This is an early **pre-release** for a few musicians to try. Expect rough edges.

## How to install
Download the zip for your system below (Linux, Windows or macOS), unzip it, and follow the install steps in [docs/TESTING.md](https://github.com/adinwalls/plugsalot/blob/main/docs/TESTING.md).

## What's new in this version
- Guitar amps: Guitarix BlueAmp (clean), Plexi (classic rock), Supersonic (high gain), Guvnor (overdrive pedal) and UltraCab (speaker cabinet). Knobs only, no files to download.

## Known issues
- The guitar amps have not been tuned by ear yet; output levels may need adjusting.
